# Simple E-Commerce Web Application

A lightweight and responsive E-Commerce web application built using HTML, CSS, and JavaScript.

## 🚀 Features
- **User Authentication:** Login and Registration pages with redirection.
- **Product Display:** Dynamically renders product items with images and prices.
- **Shopping Cart:** Add items to cart and calculate real-time total price.
- **Checkout Flow:** Interactive checkout form for placing orders.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6)
- **Environment:** Node.js (Static Server)
